PROJETO DE VIDA — NOSSO FUTURO

Arquivos:
- index.html: estrutura e conteúdo do site.
- style.css: cores, fontes, layout e responsividade.
- script.js: menu mobile e ano automático.

COMO ABRIR NO VISUAL STUDIO CODE
1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra o Visual Studio Code.
3. Vá em File > Open Folder (Arquivo > Abrir Pasta) e selecione a pasta extraída.
4. Abra o arquivo index.html.
5. Para visualizar, clique com o botão direito em index.html e escolha "Open with Live Server" (se a extensão Live Server estiver instalada). Também é possível abrir o HTML diretamente no navegador.

PERSONALIZAÇÃO
Edite os textos de cada perfil diretamente no index.html.
As cores, tamanhos e estilos ficam no arquivo style.css.
O comportamento do menu e o ano do rodapé ficam no script.js.

Observação: as fontes são carregadas do Google Fonts quando há conexão com a internet. O site funciona sem elas usando fontes alternativas.
